# AniContinue — Справка по инфраструктуре

## Сервисы и их роли

### 1. GitHub — github.com/vanillodv/anicontinue
**Что это:** Хранилище кода (репозиторий)
**За что отвечает:** Хранит весь исходный код сайта
**Как используется:** При каждом `git push` → Vercel автоматически пересобирает сайт
**Аккаунт:** vanillodv (vanillo1985@yandex.ru)

---

### 2. Vercel — vercel.com
**Что это:** Хостинг для Next.js приложений
**За что отвечает:** Запускает сайт в интернете, SSL-сертификат (HTTPS)
**Адрес:** anicontinue.vercel.app (и anicontinue.ru после DNS)
**Тариф:** Hobby (бесплатно)
**Важно:** Переменные окружения хранятся в Settings → Environment Variables

Переменные окружения в Vercel:
- `NEXT_PUBLIC_SUPABASE_URL` — адрес базы данных
- `NEXT_PUBLIC_SUPABASE_ANON_KEY` — публичный ключ Supabase
- `SUPABASE_SERVICE_ROLE_KEY` — секретный ключ Supabase (только сервер)
- `ANTHROPIC_API_KEY` — ключ API для генерации текста
- `NEXT_PUBLIC_APP_URL` — https://anicontinue.vercel.app

---

### 3. Supabase — supabase.com
**Что это:** База данных + авторизация
**За что отвечает:**
- Хранит пользователей, главы, аниме, профили
- Авторизация через Google OAuth
- RLS политики (безопасность данных)
**Тариф:** Free
**Проект:** zafbjeslpkprdqaiynqs.supabase.co

Основные таблицы:
- `profiles` — профили пользователей (лимиты генераций)
- `chapters` — сгенерированные главы
- `anime` — каталог аниме
- `suggestions` — пожелания пользователей
- `chapter_comments` — комментарии к главам
- `ai_usage_logs` — логи использования AI
- `ai_prompts` — системные промпты

---

### 4. Anthropic API — anthropic.com
**Что это:** API для генерации текста
**За что отвечает:** Генерирует фанфик-главы
**Модель:** claude-haiku-4-5-20251001
**Оплата:** По токенам (pay-as-you-go)
**Ключ:** хранится в .env.local и в Vercel

### 8. Boosty — boosty.to/anicontinue
**Что это:** Платформа для донатов
**За что отвечает:** Приём добровольных пожертвований от пользователей
**Тарифы:**
- 150₽ → 10 генераций
- 400₽ → 30 генераций
- 800₽ → 100 генераций
**Важно:** После доната пользователь пишет на support@anicontinue.ru — генерации добавляются вручную в Supabase

---

## Как добавить генерации пользователю вручную

1. Зайди на supabase.com → проект → Table Editor → таблица `profiles`
2. Найди пользователя по email
3. Увеличь значение `chapters_limit` (например с 3 до 13 если донат 10 генераций)

```bash
git add .
git commit -m "Описание изменений"
git push
```
Vercel автоматически пересобирает сайт за ~1 минуту.

## Схема работы сайта

```
Пользователь
    ↓
anicontinue.ru (домен nic.ru)
    ↓
Vercel (Next.js сайт)
    ↓
Supabase (авторизация + БД)
    ↓
Anthropic API (генерация главы)
    ↓
Supabase (сохранение главы)
    ↓
Пользователь видит главу
```
